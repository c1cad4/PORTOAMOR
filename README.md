# PORTOAMOR — публичная демонстрация для заказчика

Это **статическая версия** концепта: главная — портфолио, `shop.html` — интерактивная витрина.

**Не работает на GitHub Pages:** серверная генеративная AI-примерка, синхронизация остатков с SQLite, создание заказов, оплата, админка. 3D — концептуальные GLB-сетки, не точные цифровые двойники.

## Публикация
1. Создать **public** репозиторий `portoamor-portfolio` в GitHub.
2. Загрузить **содержимое этой папки** (не ZIP-файл) в корень ветки `main`.
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
4. Открыть `https://<USERNAME>.github.io/portoamor-portfolio/` и проверить `shop.html`.

## Важное
- Раздел «исходник» содержит **AI-концепты**, не фото реального товара.
- Ракурсы физического изделия, точный VTO и AI-видео **пока не подтверждены**.
- Не размещайте на GitHub API-ключи, исходные фотографии заказчиков или персональные данные.
- Для реальной коммерции нужны бэкенд и проверенная лицензия на изображения/модели/AI.
