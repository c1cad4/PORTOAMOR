# PORTOAMOR — AI Fashion Store Demo

Единый демонстрационный сайт fashion-магазина PORTOAMOR. `index.html` — главная страница магазина; `shop.html` сохранён как технический резервный адрес. Отдельная страница портфолио удалена.

Публичный адрес после обновления GitHub Pages: https://c1cad4.github.io/PORTOAMOR/

## Статус ресурсов
- Восстановлены 21 статическое изображение в `assets/recovered/`; на главной выведена галерея виртуальных моделей.
- Основная часть ассетов прежней полной сборки (фотографии всех 66 SKU и GLB) по-прежнему отсутствует в репозитории, поэтому для некоторых товаров изображения или 3D могут не загрузиться. Полную сборку нужно догрузить, не перезаписывая текущий `index.html`.
- GitHub Pages — статический хостинг. Серверная AI-генерация, оплата и база заказов не функционируют без отдельного backend.
- Генеративные изображения являются демо-концептами; точное соответствие реальной продукции не подтверждено.
