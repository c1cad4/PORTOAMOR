# PORTOAMOR — AI Fashion & Digital Studio

Публичная презентация fashion-концепции для заказчика. Главная страница — `index.html`, портфолио — `portfolio.html`, интерактивная витрина — `shop.html`.

**Текущий статус:** HTML-страницы загружены через GitHub. Для полного отображения изображений, 3D и JS необходимо добавить содержимое каталога `assets/` и остальные файлы из [подготовленной сборки ZIP, полученной в ChatGPT]. Не отправляйте ссылку заказчику до выполнения этой загрузки и включения GitHub Pages.

**Публикация:** сделайте репозиторий Public и включите Settings → Pages → Deploy from a branch → main / (root). Ожидаемый адрес: https://c1cad4.github.io/PORTOAMOR/

Важно: статическая версия не включает серверную AI-генерацию, оплату и базу заказов. Точные 3D-двойники изделий и коммерчески проверенная примерка не подтверждены.
